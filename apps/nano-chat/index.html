Download the on-device model?

Chrome needs its on-device Prompt API model before you can chat with that provider. The file is several gigabytes, stays in your Chrome profile, and runs locally.

  • Recommended: desktop Chrome with about 22 GB free disk
  • Remove later in Chrome Settings → System → On-device AI

Remove the model
A webpage cannot uninstall Chrome’s on-device model. Chrome menu → Settings → System → turn off On-device AI. Inspect with chrome://on-device-internals.
