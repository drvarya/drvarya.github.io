Download the on-device model?

Chrome needs Gemini Nano on this device before you can chat. The file is several gigabytes, stays in your Chrome profile, and runs locally.

  • Remove later in Chrome Settings → System → On-device AI

Remove the model
A webpage cannot uninstall Gemini Nano. Chrome menu → Settings → System → turn off On-device AI. Inspect with chrome://on-device-internals.

Docker: enable chrome://inspect/#remote-debugging, click Allow when Chrome prompts, then Refresh.
